# Export a lightweight *measured* resort DEM (staging only)

This is the next step after the generic OSM index, DEM coverage gate and
survey-to-network conversion. It transforms a **locally reconstructed and
previously audited** IGN LiDAR HD ground mosaic into a small game-coordinate
EPSG:2154 JSON grid. It uses the same row orientation and metadata field
names as the existing `Reality` assets.

**Current status:** generator and tests exist, but *no real high-mountain
asset has been produced, promoted or shipped*. The genuine 24 source
GeoTIFFs are not in the GitHub repo; the earlier audited CI run created them
in temporary storage. They must be retrieved again from official sources
or regenerated by the verified MNT mosaic workflow.

Example, from a local session which already has the audited real mosaic:

```sh
/usr/bin/python3 tools/reality/export_measured_resort_grid.py \
  --index docs/p4/JANDRI-OSM-INDEX.json \
  --report /tmp/jandri-measured-report.json \
  --mosaic /tmp/jandri-measured-mnt/measured-jandri-source-only.vrt \
  --tiles-dir /tmp/jandri-measured-mnt \
  --name 'Jandri 2' --step 15 \
  --out /tmp/jandri2-measured-staging.json
```

The exporter:
- Checks that the previously measured report says the official 24-tile
  mosaic and original OSM profiles completed successfully.
- Re-hashes the **actual 24 original TIFFs**, refusing a missing or
  tampered source.
- Uses the original OSM nodes, not a simplified or synthetic piste path.
- Crops to the surveyed route envelope plus 45m margins; samples genuine
  ground height at every output cell. Fails for any nodata/invalid cell
  instead of extrapolating a new mountain.
- Resamples every original centreline at no more than 5m to catch a
  missing real height between sparse OSM vertices.
- Enforces the existing `Reality` per-axis 1200-cell ceiling and a
  1.44-million-cell cap. If the route is bigger, rejects it and requests
  explicit tiled assets rather than silently lowering quality.

**Output is NOT a game-ready playable resort**: its schema is
`cold-smoke-measured-dem-staging/v1` and
`approvedForGameplay:false`. It does not include finalized downhill
direction, resort-wide topology, marked groomed piste boundaries,
hazards, station exits, graphics LOD or a published cache strategy.
The existing physics, terrain shader, resort list and homepage are unchanged.

The independent route/geography approvals and browser performance
regression are prerequisites for promoting this staging grid to a new,
lazy-loaded real resort pack. Avoid merging a multi-megabyte height array
into the HTML shell.
