# Jandri 缆车：正常乘坐 / 直达终点站

这是一项**未来缆车系统的交互设计与逻辑测试**，尚未在当前游戏启用。Jandri I / II 的上游 OSM 线路已经通过 OpenSkiData 找到，但车站的准确乘降点、场地安全出口和进出雪道通道仍未完成审核。

## 两种乘坐方式

玩家在已审核的缆车下站、通过登车检查之后，可选择：

- **正常乘坐**：观看乘坐过程；在上站正常下车。
- **直达终点站**：立即结束乘坐动画，直接进入**同一个已审核上站下车点**，无需等待模拟行程。

直达功能并非随意传送。它只允许在玩家已经乘上该缆车时使用，不允许从山上、另一条缆车、未经确认的接驳点触发。上下站、运营方向、登车许可、场地离地高度、下车安全区和出口均须由独立资料确认。真实车站资料不齐时，两个选项均不可开放为正式游戏功能。

实现约束位于 `tools/reality/lift_ride_flow.cjs`，测试位于 `test/lift-express-exit.test.cjs`。这是未来运行时接入的安全状态机与接口契约，**不是当前已实现的乘坐 UI 或传送逻辑**。

即使 OpenSkiData 的线路记录标为 `operating`，也不能据此断言该日缆车开放、可上车。官方运营资料和 IGN LiDAR HD 下车点的地形验证仍是独立的发布门槛。

后续实现：正式缆车上下站坐标验证 → 可接驳的雪道/站区边界验证 → 乘坐动作与摄像机 → 同步接入两个按钮 → 浏览器测试与性能审查。
